## What this tool does

**fluent_intl** is the zero-setup CLDR backend for fluent_bundle — real cardinal plural rules for every CLDR locale plus 42 inlined ordinal locales, and locale-aware number / currency / date-time formatting, all through `package:intl` (+ `l10n_currencies` for spelled-out currency names). Pure Dart, no init, no assets: construct `IntlBackend()` and go. The lightweight default backend of the family.

## Tool-specific notes

- **The degrade contract is sacred.** An option intl has no knob for (`roundingMode`, `signDisplay`, units, calendars, time zones) renders the nearest supported form AND records a `FluentTypeError` — never a silent drop, never a throw.
- **Ordinals are this package's contribution** — intl ships none. The 42 inlined ordinal locales are CLDR-compliance-tested against an autogenerated fixture; a new locale's rules come WITH the fixture regeneration, never hand-written expectations.
- **The `platforms` gate is blocked-loud pre-release** — pana can't resolve the sibling-repo path dep; the family release checklist flips it in.
