# fluent_intl — Capabilities

What this backend renders, where it degrades, and why. For how it's wired see [`ARCHITECTURE.md`](ARCHITECTURE.md); for maintenance recipes see [`UPDATING.md`](UPDATING.md).

**The family option matrix is single-sourced.** The full ECMA-402
option × backend table (every NUMBER option, ✓ render / ✗
degrade-with-error per backend, no blank cells) lives in
[`fluent_bundle/docs/CAPABILITY_ROADMAP.md`](../../fluent_bundle/docs/CAPABILITY_ROADMAP.md)
— it is NOT duplicated here. This file adds only what is intl-specific.

---

## Table 1 — The positioning

| Property | fluent_intl | (contrast: fluent_icu) |
|---|---|---|
| Engine | `package:intl` — pure Dart, CLDR compiled in | icu_kit — vendored ICU4X, 3 engines |
| Setup | none (sync construction, no init) | one `IcuBackend.init()` |
| Binary/data cost | intl's compiled tables only | ICU4X binary or WASM (or zero via browserIntl) |
| Ceiling | intl's API surface — no rounding modes, no calendars, no time zones | ICU4X's data — a few notation/sign walls |
| For | apps already on intl / Flutter l10n; smallest footprint | full ECMA-402 fidelity |

## Table 2 — The ✗ set (intl-side cells of the family matrix)

Everything here is an **API ceiling** — `package:intl` exposes no knob
for it, so no amount of adapter work renders it. Each degrades loud:
nearest supported rendering + a recorded `FluentTypeError`,
harness-proven both directions.

| Option | Degrade behavior | Retire when |
|---|---|---|
| `signDisplay` | default sign rendering | intl grows the API (no upstream signal) |
| `roundingMode` / `roundingPriority` / `roundingIncrement` | half-even default rounding | same |
| `trailingZeroDisplay: stripIfInteger` | zeros kept per digit bounds | same |
| `numberingSystem` | locale-default digits | same |
| Grouping strategies (`min2` / `always` / `auto` as distinct) | boolean grouping only | same |
| `notation: engineering` | renders scientific (`#E0`) | same |
| DATETIME `calendar` | gregorian only | same |
| DATETIME `timeZone` / `timeZoneName` | local-time rendering | same |
| DATETIME `numberingSystem` | locale-default digits | same |

Unlike icu's walls (data gaps with live upstream issues), these have no
tracked upstream path — `package:intl`'s formatter API has been stable
for years. The retire trigger is a dep-bump review ([`UPDATING.md`](UPDATING.md) §1).

## Table 3 — intl-specific capabilities beyond the family matrix

| Capability | Status | Notes |
|---|---|---|
| `notation: scientific` (decimal style) | DONE | intl's `#E0` pattern — real but coarse (no mantissa digit shaping); icu degrades this one |
| `currencyDisplay: name` | DONE | composed via `l10n_currencies` localized names (~149 locales) — intl itself has no name display |
| Ordinal plurals | DONE — 42 locales | intl ships no ordinal rules; the 42 CLDR locales with non-trivial rules are inlined and CLDR-compliance-tested (icu covers all locales) |
| Cardinal plurals | DONE | `Intl.pluralLogic`, every locale intl ships |
| Compact notation (short/long, compactDisplay) | DONE | `NumberFormat.compact*` constructors |

## Table 5 — Won't do

| Capability | Reason |
|---|---|
| Hand-rolling rounding modes / numbering systems / calendars on top of intl | That's reimplementing ICU in Dart — the icu satellite exists for fidelity. This package stays the thin, honest adapter. |
| Post-processing intl's output strings to fake unsupported options | String surgery on localized output breaks in locales the author didn't test. Degrade loud instead. |
| Silent option drops | The degrade contract forbids it; the harness enforces it. |
